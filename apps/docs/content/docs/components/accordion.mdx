---
title: Accordion
description: Collapsible item list with height animation, wrapping Radix Accordion.
---

`Accordion` wraps `@radix-ui/react-accordion`. Content height animates
against Radix's measured `--radix-accordion-content-height` CSS variable on
the `data-[state]` selectors (the pattern from the Radix docs), and the
whole transition disappears under `motion-reduce`.

## Installation

```tsx
import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from "@srui/react";
```

## Props

| Export | Notes |
|---|---|
| `Accordion` | Root: `type="single" \| "multiple"`, `collapsible`, `defaultValue` |
| `AccordionItem` | One panel; `value` required |
| `AccordionTrigger` | Header button; chevron rotates when open |
| `AccordionContent` | Animated body |

## Accessibility

Full `accordion` ARIA pattern from Radix: triggers expose
`aria-expanded`/`aria-controls`, panels are labelled by their triggers,
arrow keys and Home/End navigate between headers. The height transition
carries a `motion-reduce:transition-none` override.
