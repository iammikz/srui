title: App Shell

`AppShell` is the page-level super-component: a fixed-width desktop sidebar
(`--sidebar*` tokens) that collapses into a **Dialog-based drawer** below the
768px breakpoint — it reuses Phase 0's `Dialog` rather than a second overlay
system. The main content area keeps a stable width across the swap.

## Installation

```tsx
import { AppShell, NavigationMenu } from "@iammikz/srui";
```

## Usage

<AppShellDemo />

```tsx
<AppShell
  sidebar={
    <NavigationMenu
      variant="sidebar"
      items={navigationItems}
      activeHref={currentPath}
    />
  }
  topbar={<span>Acme Admin</span>}
  breadcrumbs={[
    { label: "Home", href: "/" },
    { label: "Projects", href: "/projects" },
    { label: "srui" },
  ]}
>
  <main>your page</main>
</AppShell>
```

`AppShell` provides the layout and accepts sidebar content. Compose it with
[`NavigationMenu`](/components/navigation-menu) for expandable navigation
up to three levels. `navigationItems` is the nested item data and
`currentPath` is the current page URL. The docs app shell uses this same
combination, with **Components → category → component** in its sidebar.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `sidebar` | `ReactNode` | — | Sidebar content (docked ≥768px, drawer below) |
| `topbar` | `ReactNode` | — | Topbar content (a menu button is added below 768px) |
| `breadcrumbs` | `{ label: string; href?: string }[]` | — | Breadcrumb trail; last item is `aria-current="page"` |
| `children` | `ReactNode` | — | Main content |
| `sidebarCollapsible` | `boolean` | `false` | Adds a desktop hamburger button to hide/show the sidebar |
| `closeOnSelect` | `boolean` | `false` | Closes the mobile drawer on link selection; also hides the desktop sidebar when `sidebarCollapsible` is enabled |

## Hiding the sidebar

Both behaviors are opt-in:

```tsx
<AppShell
  sidebarCollapsible
  closeOnSelect
  sidebar={
    <NavigationMenu
      variant="sidebar"
      items={navigationItems}
      activeHref={currentPath}
    />
  }
>
  {children}
</AppShell>
```

`sidebarCollapsible` adds a desktop hamburger button. Hiding the sidebar
frees its width for the main content and preserves expanded navigation
groups when you reopen it. The desktop hidden state survives viewport
changes; mobile drawer state is separate.

`closeOnSelect` reacts to enabled sidebar links (`a[href]`), including router
links and keyboard activation. Expanding a group keeps navigation open.
Modified clicks (Ctrl, Cmd, Shift, or Alt), download links, and links targeting
another window keep it open too. Sidebar footer actions do not trigger it.
Custom button-based navigation can use the headless hook in a custom layout.

With only `closeOnSelect`, desktop navigation stays docked and mobile link
selection closes the drawer. With only `sidebarCollapsible`, hiding and
showing desktop navigation is manual. With neither, the existing fixed
desktop sidebar and mobile drawer behavior is unchanged.

## Tier 2 — slots and classNames

```tsx
<AppShell
  sidebar={…}
  slots={{ topbarEnd: <Badge>live</Badge>, sidebarFooter: <UserCard /> }}
  classNames={{ root: "…", sidebar: "…", topbar: "…", main: "…", breadcrumbs: "…" }}
/>
```

`classNames` keys map one-to-one to the DOM parts: `root`, `sidebar`,
`topbar`, `main`, `breadcrumbs`.

## Tier 3 — useAppShell()

The headless hook: the 768px media-query flag plus drawer open state.

```tsx
const { isDesktop, drawerOpen, setDrawerOpen, openDrawer, closeDrawer } =
  useAppShell();
```

Build a completely different shell (e.g. a collapsible icon rail) on top of
it — the hook returns state and handlers only, no JSX.
Each hook call owns its own state; it does not control an existing
`<AppShell>`. Use the props above for the built-in shell.

## Accessibility

- The drawer is a Radix `Dialog`: focus trap, `aria-modal`, Escape to close,
  focus returns to the menu button.
- Breadcrumbs are a `nav[aria-label]` with an ordered list; the current page
  carries `aria-current="page"`.
- Crossing the breakpoint closes the drawer, so navigation is never
  duplicated between drawer and docked sidebar.
- The hamburger reports `aria-expanded` and `aria-controls`. Closing the
  drawer or selecting a link that hides desktop navigation returns focus
  to the hamburger.
