`Carousel` is an embla-powered carousel: drag/scroll-snap content, arrow
controls that disable at the ends, horizontal or vertical.

## Installation

```tsx
import { Carousel, CarouselContent, CarouselItem, CarouselPrevious, CarouselNext } from "@iammikz/srui";
```

## Usage

  <CarouselContent>

## Exports

| Export | Notes |
|---|---|
| `Carousel` | `orientation="horizontal" \| "vertical"`, `opts` (embla options), `setApi` |
| `CarouselContent` / `CarouselItem` | The track and slides — size slides via `className` (`basis-1/3` etc.) |
| `CarouselPrevious` / `CarouselNext` | Round arrow buttons; auto-disabled at the ends |
| `useCarousel()` | `{ api, scrollPrev, scrollNext, canScrollPrev, canScrollNext, orientation }` |

## Accessibility

The region is `aria-roledescription="carousel"`, slides are
`role="group"`/`aria-roledescription="slide"`, and arrow keys scroll when
the carousel itself is focused.
