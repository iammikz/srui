`ColorPicker` is a swatch trigger opening an anchored color panel: a
saturation/value square, a hue slider, an optional alpha slider, a hex field
where typed input commits (`f09`, `#FF6600`, `rgba(37,99,235,.8)` all
parse), preset swatches, and the screen eyedropper where the browser
supports it. Values are normalized hex keys — `#RRGGBB`, or `#RRGGBBAA`
with `alpha`.

## Installation

```tsx
import { ColorPicker } from "@iammikz/srui";
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | — | `'#RRGGBB'`, or `'#RRGGBBAA'` with `alpha` (controlled) |
| `defaultValue` | `string` | — | Initial color |
| `onChange` | `(color: string) => void` | — | Fires live with the normalized hex key |
| `alpha` | `boolean` | `false` | Alpha slider + 8-digit hex values |
| `presets` | `string[]` | — | Swatch row inside the panel |
| `eyedropper` | `boolean` | `true` | Screen eyedropper button where supported |
| `placeholder` / `ariaLabel` / `disabled` / `invalid` / `clearable` | — | — | Usual field props |
| `format` | `(color: string) => string` | — | Custom trigger display |
| `name` | `string` | — | Hidden input for native form posts |

## Accessibility

- Combobox trigger semantics over a `role="dialog"` panel; Escape and
  outside clicks close and refocus.
- The SV square is a focusable `role="slider"` labelled "Saturation and
  brightness" announcing the live color; arrow keys nudge saturation and
  brightness (Shift = 5×). Hue and alpha are full Radix sliders.
- Preset swatches announce their hex; the eyedropper button is labelled
  and simply hidden on browsers without the EyeDropper API.

## Edge cases

- Typed input only commits when fully parseable; blur reverts bad drafts.
- `toCssString('#2563EBCC')` → `rgba(37, 99, 235, 0.8)` — use it when
  feeding CSS directly; the value itself always stays a hex key.
- Color math helpers (`hexToRgb`, `rgbToHsv`, `parseColorInput`, …) are
  exported from the package root, same as the date helpers.
