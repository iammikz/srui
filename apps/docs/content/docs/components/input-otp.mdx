`InputOTP` is a verification-code input: keyboard- and paste-driven, styled
slot groups, screen-reader friendly.

## Installation

```tsx
import { InputOTP, InputOTPGroup, InputOTPSlot, InputOTPSeparator } from "@iammikz/srui";
```

## Usage

<LivePreview code={`<InputOTP maxLength={6} value={v} onChange={setV}>
  <InputOTPGroup>
    <InputOTPSlot index={0} /> <InputOTPSlot index={1} /> <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} /> <InputOTPSlot index={4} /> <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>`}>
  <InputOTPDemo />
</LivePreview>

## Exports

| Export | Notes |
|---|---|
| `InputOTP` | Root; `maxLength` (code length), `value`/`onChange`, `pattern` (default digits), `autoFocus` |
| `InputOTPGroup` | Slot cluster |
| `InputOTPSlot` | One character cell — `index` required; shows caret/caret-blink when active |
| `InputOTPSeparator` | The dash between groups |

## Accessibility

The input itself is screen-reader-only; slots announce as labelled cells and
the caret blink is disabled under `prefers-reduced-motion`.
