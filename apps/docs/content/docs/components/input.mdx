title: Input

---

`Input` is a native `<input>` styled through the token contract: the field
tint is `bg-input/30`, focus uses the `--ring` outline, and `invalid` swaps
both to `--destructive`.

## Installation

```tsx
import { Input } from "@iammikz/srui";
```

## Usage

<LivePreview code={`<Input placeholder="Email address" />`}>
  <Input placeholder="Email address" className="w-72" />
</LivePreview>

```tsx
<Input placeholder="Email address" />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `invalid` | `boolean` | `false` | Red border + `aria-invalid="true"` |
| ...props | `React.InputHTMLAttributes<HTMLInputElement>` | `type="text"` | All native input attributes |

`type="file"` inputs are styled: the file button renders transparent with
foreground text, matching the field.

## Accessibility

- Native `<input>`; label it with `Label` + `htmlFor`, or wrap it in
  `FormField` which wires that up.
- `invalid` sets `aria-invalid` — pair it with an error message in
  `role="alert"` (see `FormField`).
- Focus is visible via a 2px `outline-ring` with offset, on `:focus-visible`
  only, so pointer clicks don't show a ring.
