title: Item
description: List-item layout primitive — media, content, end slots.
---

`Item` is the list-row layout: leading media, a title/description block, and
a trailing end slot. Lists, cards, notifications, search results.

## Installation

```tsx
import { Item, ItemMedia, ItemContent, ItemTitle, ItemDescription, ItemEnd } from "@iammikz/srui";
```

## Exports

| Export | Notes |
|---|---|
| `Item` | `variant="row"` (default) or `"column"` |
| `ItemMedia` | `align="start"` pins it to the first text line |
| `ItemContent` / `ItemTitle` / `ItemDescription` | The text block |
| `ItemEnd` | Trailing slot, vertically centered |
