---
title: Menubar
description: Horizontal menu bar (File, Edit, View…), wrapping Radix Menubar.
---

`Menubar` is the desktop-app menu bar: a row of triggers, each opening a
dropdown with the same items API as DropdownMenu.

## Installation

```tsx
import { Menubar, MenubarMenu, MenubarTrigger, MenubarContent, MenubarItem } from "@iammikz/srui";
```

## Exports

`Menubar, MenubarMenu, MenubarTrigger, MenubarContent, MenubarItem`
(`variant="destructive"`, `inset`), `MenubarCheckboxItem`,
`MenubarRadioGroup`, `MenubarRadioItem`, `MenubarLabel`, `MenubarSeparator`,
`MenubarShortcut`, `MenubarGroup`, `MenubarSub`, `MenubarSubTrigger`,
`MenubarSubContent`.

## Accessibility

Full Radix menu keyboard model: triggers arrow between menus, type-ahead
inside, Escape closes; the bar keeps a roving tab stop.
