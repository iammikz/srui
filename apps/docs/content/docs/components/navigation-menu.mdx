`NavigationMenu` is the header-navigation pattern: a row of links and
triggers whose content panels fly out into a shared animated viewport.

## Installation

```tsx
import {
  NavigationMenu, NavigationMenuList, NavigationMenuItem, NavigationMenuTrigger,
  NavigationMenuContent, NavigationMenuLink, NavigationMenuIndicator, NavigationMenuViewport,
} from "@iammikz/srui";
```

## Exports

| Export | Notes |
|---|---|
| `NavigationMenu` / `NavigationMenuList` / `NavigationMenuItem` | Root/list/item |
| `NavigationMenuTrigger` | Opens the item's content; chevron rotates when open |
| `NavigationMenuContent` | The flyout markup — composes any layout (grids, lists) |
| `NavigationMenuLink` | Styled link; `active` prop for the current page |
| `NavigationMenuIndicator` / `NavigationMenuViewport` | The active dot + the shared animated panel — render once per menu |

## Accessibility

Full Radix keyboard model: tab to a trigger, arrows between items, Enter or
arrow-down opens content, Escape closes. Links expose standard semantics.
