---
title: Pagination
description: Standalone page navigation for row lists — nav + list semantics, current-page marking, and an ellipsis range hook.
---

`Pagination` navigates paged data outside `DataTable` (which has its own
built-in): a labelled `nav` with an ordered list of page buttons, previous/
next, and ellipsis collapse for long ranges via the `usePaginationRange` hook.

## Installation

```tsx
import {
  Pagination, PaginationContent, PaginationItem, PaginationLink,
  PaginationPrevious, PaginationNext, PaginationEllipsis, usePaginationRange,
} from "@iammikz/srui";
```

## Usage

A typical list: slice the rows by page, derive `totalPages`, render the nav.
44 invoices at 4 per page → 11 pages, with the ellipsis window around the
current page:

<LivePreview code={`const ORDERS = [/* 44 rows */];
const PER_PAGE = 4;

const [page, setPage] = useState(5);
const totalPages = Math.ceil(ORDERS.length / PER_PAGE);
const range = usePaginationRange(page, totalPages);
const rows = ORDERS.slice((page - 1) * PER_PAGE, page * PER_PAGE);

<div className="flex flex-col gap-4">
  <ul className="rounded-md border border-border">
    {rows.map((order) => (
      <li key={order.id} className="flex items-center justify-between border-b border-border px-3 py-2 text-sm last:border-b-0">
        <span className="font-mono text-xs">{order.id}</span>
        <span className="text-xs text-muted-foreground">\${order.total}.00 · {order.status}</span>
      </li>
    ))}
  </ul>

  <Pagination>
    <PaginationContent>
      <PaginationItem>
        <PaginationPrevious disabled={page === 1} onClick={() => setPage(p => p - 1)} />
      </PaginationItem>
      {range.map((item) => (
        <PaginationItem key={item}>
          {item === "ellipsis-start" || item === "ellipsis-end" ? <PaginationEllipsis /> : (
            <PaginationLink isActive={item === page} onClick={() => setPage(item)}>
              {item}
            </PaginationLink>
          )}
        </PaginationItem>
      ))}
      <PaginationItem>
        <PaginationNext disabled={page === totalPages} onClick={() => setPage(p => p + 1)} />
      </PaginationItem>
    </PaginationContent>
  </Pagination>
</div>`}>
  <PaginationDemo />
</LivePreview>

### Real links (asChild)

`<Link>` in an SPA — instead of a `<button>`, keeping `isActive` styling

## Exports

| Export | Notes |
|---|---|
| `Pagination` | `nav` wrapper, `aria-label="Pagination"` |
| `PaginationContent` / `PaginationItem` | The `ol`/`li` structure |
| `PaginationLink` | Page button; `isActive` sets `aria-current="page"`; `asChild` renders an `<a href>` child instead of a `<button>` |
| `PaginationPrevious` / `PaginationNext` | Edge buttons with chevrons; `disabled` at the bounds |
| `PaginationEllipsis` | The `…` marker (hidden from assistive tech) |
| `usePaginationRange(page, totalPages, siblings?)` | `1 … 4 5 6 … 12` window; first/last always shown, `siblings` (default 1) around the current page |

## Wiring checklist

1. `totalPages = Math.ceil(rows.length / perPage)` — never hardcode it.
2. `rows.slice((page - 1) * perPage, page * perPage)` for the visible page.
3. Clamp `page` when the data shrinks (`setPage(p => Math.min(p, totalPages))`).
4. For server-side paging, fetch on `page` changes and drive the same nav.

## Accessibility

The nav is labelled; the current page carries `aria-current="page"` plus the
selected treatment; Previous/Next announce themselves and disable at the
bounds; ellipses are decorative.

Short ranges (≤ 6 pages with the default siblings) render every page with no
ellipses. For tables with toolbar/filter/CSV needs, prefer `DataTable`'s
built-in pagination instead of wiring this by hand — it covers server-side
paging too (`manualPagination` + `rowCount`; see
[Data Table](/components/data-table)).
