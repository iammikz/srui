title: Popover

---

`Popover` wraps `@radix-ui/react-popover`. It shares `DialogContent`'s
treatment (`surface`, `bg-popover`, `animate-scale-in`) but is **non-modal**
— the page stays interactive while it's open.

## Installation

```tsx
import { Popover, PopoverTrigger, PopoverContent, PopoverAnchor } from "@srui/react";
```

## Props

| Export | Notes |
|---|---|
| `Popover` | Root; `open`/`onOpenChange` for controlled use |
| `PopoverTrigger` | The toggle target (`asChild` supported) |
| `PopoverAnchor` | Position against an element without making it the trigger |
| `PopoverContent` | The panel; `align` (default `"center"`), `sideOffset` (default `6`), Radix Content props |

## Accessibility

Radix wires `aria-expanded`/`aria-controls` on the trigger; Escape closes
and returns focus to the trigger; outside clicks dismiss. Because it is
non-modal, focus is *not* trapped — don't put critical flows in a popover
that would be lost by an outside click.
