---
title: Radio Group
description: Single-choice radio set, wrapping Radix RadioGroup.
---

`RadioGroup` wraps `@radix-ui/react-radio-group`: arrow-key selection,
`bg-primary` checked dot on `--dur-fast` transitions, plain-`<label>`
compatible.

## Installation

```tsx
import { RadioGroup, RadioGroupItem } from "@iammikz/srui";
```

## Usage

## Props

| Export | Notes |
|---|---|
| `RadioGroup` | Root: `value`/`onValueChange`, `orientation`, `disabled`, `invalid` (destructive rings on the items + `aria-invalid`) |
| `RadioGroupItem` | One option: `value`, `disabled` |

`aria-invalid` on the group.

## Accessibility

Full `radiogroup` ARIA pattern via Radix: arrow keys move selection,
`aria-checked` on items, labels give each radio its accessible name.
