`Timeline` is the activity feed: one item per event, a status marker on a
connecting spine, and a right-aligned timestamp slot. Purely
presentational — feed it ordered data and it stays an ordered list.

## Installation

```tsx
import { Timeline, TimelineItem } from "@iammikz/srui";
```

## Props

`Timeline` accepts `ol` props. `TimelineItem`:

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `ReactNode` | — | The event (bold first line) |
| `description` | `ReactNode` | — | Body copy |
| `time` | `ReactNode` | — | Right-aligned timestamp |
| `icon` | `ReactNode` | — | Custom marker instead of the dot |
| `variant` | `"default" \| "info" \| "success" \| "warning" \| "destructive"` | `"default"` | Dot tone |

## Accessibility

An `ol`/`li` list — screen readers announce the event order; the spine and
dots are decorative.

Upgrades over the PRUI original: the timestamp slot and per-item markers.
