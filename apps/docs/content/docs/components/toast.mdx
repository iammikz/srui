title: Toast
description: Timed notifications via a ToastProvider and a useToast() hook, wrapping Radix Toast.
---

`Toast` wraps `@radix-ui/react-toast`. Put `ToastProvider` once near the
app root (alongside `UIProvider`); any component below it calls
`toast({...})` to show a dismissible, auto-expiring notification.

## Installation

```tsx
import { ToastProvider, useToast } from "@iammikz/srui";
```

Wrap your app:

```tsx
<UIProvider>
  <ToastProvider>
    <App />
  </ToastProvider>
</UIProvider>
```

## Usage

<ToastDemo />

```tsx
const { toast } = useToast();

toast({
  title: "Saved",
  description: "Your changes are live.",
  variant: "success",
});
```

## toast() options

| Option | Type | Default | Description |
|---|---|---|---|
| `title` | `string` | — | Heading line |
| `description` | `string` | — | Body text |
| `variant` | `"default" \| "success" \| "destructive"` | `"default"` | `success` uses `bg-success`, `destructive` uses `bg-destructive` |
| `action` | `{ label: string; onClick: () => void }` | — | Optional action button |

Toasts auto-expire after 5 seconds; swipe right or press the ✕ to dismiss
early.

## Accessibility

Each toast is `role="alert"`-adjacent (Radix announces the region);
destructive toasts get extra prominence via color and the title text.
Escape dismisses the focused toast, and every toast has a labeled close
button. The action button provides `altText` for screen readers.
