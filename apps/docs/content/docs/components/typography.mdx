---
title: Typography
description: Styled semantic text on the design tokens.
---

`Typography` maps text styles to semantic elements — headings, body copy,
leads, muted text, blockquotes, lists, and code — all on the token system.

## Installation

```tsx
import { Typography } from "@iammikz/srui";
```

## Usage

## Variants

`h1` `h2` `h3` `h4` `p` `lead` `large` `small` `muted` `blockquote` `ul`
`code` `inlineCode` — each maps to its semantic element; pass `asChild` to
render your own element with the style. All accept `className` overrides.
