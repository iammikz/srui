**srui** is a React component library for Tailwind CSS v4. It ships
shadcn-style design tokens, animated charts and loaders, and
super-components — all available in **four visual presets** you can switch
at runtime, with no page reload and no duplicated markup.

Unlike copy-in component libraries, srui is distributed as an npm package
(`@srui/react`). The components are the product: you install them, wrap
your app in `<UIProvider>`, and they stay up to date. You style them with
tokens, not by editing their source.

This site is itself built with `@srui/react` — the sidebar, the switcher
above, the tabs and callouts on this page are the real components, live.

## Why four presets?

Most UI kits commit to one aesthetic. srui treats the aesthetic as a
*runtime setting*: the same component tree can render as clean **flat**,
translucent **glass**, extruded **neumorphic**, or beveled **skeuomorphic** —
because every visual decision routes through the token contract (colors,
shadows, gradients, blur, radii, motion) instead of hard-coded values.
